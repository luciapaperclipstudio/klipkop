# KLIPKOP

Single-page landing site for KLIPKOP, a fictional independent art gallery on Albert Road, Woodstock, Cape Town.

> Art from down the road. Come look.

This is a design mock-up. All artists, artworks, addresses and contact details are invented.

## What's in it

One self-contained `index.html` (no build step), styled like a printed exhibition catalogue:
masthead, cover story, contents, four artist spreads, the collection, manifesto, visit info with a hand-drawn map, and The Kyk Letter sign-up.

Fonts: Fraunces, DM Sans, DM Mono and Caveat from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
